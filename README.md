# 番茄

一款离线的 Android 番茄钟应用。纯白 / 纯黑界面、玻璃流动触感、专注计时圆环和悬浮底部导航。功能组织参考番茄 ToDo，界面和代码独立实现。

## 安装

将 `dist/Fanqie-2.6.0.apk` 传到 Android 手机，点击安装；按手机提示允许文件来源安装应用。支持 Android 8.0（API 26）及以上。首次开始专注或环境声音时可允许通知，用于后台状态、暂停按钮及到时提示。

## 2.6.0  液态玻璃与导航触感

照片背景支持清透、柔雾和轻量材质，可在外观面板预览。手机底栏和宽屏平板侧栏支持拖动切换，系统设置允许时跨过栏目会有轻触反馈，可在应用设置中关闭。

## 2.5.2：任意倒计日都可每年重复

添加或编辑倒计日时可直接选「每年重复」，适用于生日、周年和固定日期的节日。重复方式和事项分类独立设置，过了当天后自动显示下一年的倒计日。

## 2.5.1：不限时自由专注和快捷倒计日

首页增加明显的自由专注卡片，不用设定时长，从 00:00 正向累计，暂停、继续和手动结束复用原生计时。再次进入已有自由专注保留时间；切换其他正在进行的计时需要明确保存当前后开始，返回或取消不影响原计时。

倒计日可直接输入年份、选择月份和日期，提供今天、明天、一周后、30 天后快捷项。新增「生日 · 每年重复」入口，自动按所选月日计算下一次生日，编辑时保留原始生日。2 月 29 日在平年按 2 月 28 日计算，闰年恢复 2 月 29 日。输入不存在的日期或超出 1900–2200 年时阻止保存。

## 2.5.0：待办 → 圆环选择 → 全屏计时

首页展示待办封面卡片，右上角「＋」进入圆环选择页，填写名称、选择番茄钟 / 正计时 / 倒计时及自定义时长，再明确点击开始进入全屏数字圆环。可仅保存待办，返回和取消不会改变已有计时。卡片支持预设配色或当前自选背景照片，所有页面沿用纯白、纯黑或照片液态玻璃。

计时中点击全屏待办名称可以切换计划，保留当前时长、倒计时截止时间及暂停状态。切换前时间记入原计划，切换后时间记入新计划，分段保存避免重复统计。也可以在选择页明确选择保存原计划并按新设置开始。备份保留分段时间边界。

## 2.4.3：应用名改为「番茄」

桌面、应用内标题、设置、小组件、通知和导出文件名称统一为「番茄」。保留原应用标识与签名，可直接覆盖安装并沿用已有计时、记录、设置和图片。

## 2.4.2：上传图片后玻璃随图变色

从相册导入或替换图片后，背景、玻璃底色、图表强调色、系统栏和二级专注页随新图更新。冷色照片呈现轻微冷色玻璃，暖色照片呈现轻微暖色玻璃，仍可选择深浅文字和玻璃材质。

取色仅在导入时对 24×24 样本计算并保存；已有图片按需读取小尺寸样本补齐配色，计时和页面刷新不会反复解码图片。ZIP 备份保留配色，也兼容旧版没有配色字段的图片。替换图片更新背景及缩略图缓存标识，取消选图则保留原图。纯白 / 纯黑仍可独立选择。

## 2.4.1：四种预设同步切换界面配色

修复「潮汐、落日、星夜」只换壁纸、按钮和弹窗仍沿用同一套蓝绿色的问题。晨雾使用雾蓝，潮汐使用海蓝，落日使用暖粉，星夜使用蓝紫；专注、计划、倒计日、统计、表单弹窗、导航与专注详情同步换色，Android 系统栏也跟随。

渐变预设仍可单独选择深浅文字、调整玻璃透明度与材质，纯白 / 纯黑和自定义照片的行为保持独立。外观事件只绑定真实按钮，避免点击冒泡到页面容器造成重复保存。

## 2.4.0：舒适纯色与可选照片背景

- 外观面板顶部直接选择「浅色模式」或「深色模式」：纯白或纯黑底，卡片和文字采用中性灰阶。首次安装默认纯白，选择会保存在本机。
- 主页、统计、任务、弹窗、专注详情及 Android 系统栏同步切换；黑色翻页时钟继续保持黑色。
- 可以从相册上传自己的图片，也可重新选择「我的图片」或「一键照片液态玻璃」。切换纯色只隐藏图片，不删除本机副本。
- 二级专注页严格跟随所选背景。即使保存了照片，选纯白 / 纯黑时也不会自动显示旧照片。
- 纯色模式关闭没有视觉收益的背景采样与模糊，按钮保留玻璃流动反馈。照片模式继续支持清透、柔雾、轻量、遮罩和文字保护。
- ZIP 备份保留所选纯色模式及可选图片；移除图片时返回当前深浅模式对应的纯色。

## 2.3.0：独立二级专注页

点击首页圆形计时器或「专注详情」进入，参考用户提供的专注详情截图，显示铺满当前窗口的照片、寄语、大圆环、电子数字、事项与当前状态。主页继续保留原有布局。

- 复用同一个原生计时器；进入页面不自动开始，暂停、继续、重置和结束保存沿用原有流程。
- 可以在二级页调整环境声音、照片与玻璃，收起控制，切换 Android 系统栏显示，或继续进入黑色翻页计时钟。
- 返回顺序为弹窗 → 二级页、翻页钟 → 二级页、二级页 → 主页，计时持续。自然完成在二级页上方显示结果。
- 二级页的背景与玻璃设置入口是全应用外观设置，图片保存在本机。2.4.0 起严格跟随所选纯色或照片背景。
- 圆环根据可用的剩余空间缩放，适配横竖屏、显示缩放与分屏尺寸。电子数字使用本地 SVG，无需下载字体。
- 前后台恢复、系统栏切换及进入／退出详情不会创建额外计时任务；亮屏继续遵循原有设置，暂停后不额外持有亮屏。

## 2.2.0：照片液态玻璃与日历统计

参考用户提供的统计卡片结构，保留原有纯白默认界面和一加 Pad 3 Pro 布局。

- **选自己的背景图**：统计页新增「选择背景图」，也可从页头图片按钮进入相册。系统选图后自动启用照片液态玻璃，保留清透、柔雾、轻量材质，模糊、遮罩、图片位置与深浅文字可调。图片只复制到本机私有目录，可离线使用。
- **一键照片玻璃**：外观面板可为已保存的图片恢复玻璃配方，卡片、按钮、导航与弹窗统一处理。新导入照片启用清透材质，背景遮罩 20、玻璃设置 56，并打开文字保护。
- **文字保护**：照片卡片保留最低遮盖度，改善文字与坐标轴的辨识度。需要更透明时可关闭，再自由调整玻璃遮盖度。此偏好随 ZIP 备份保存和恢复。
- **累计与当日概览**：累计次数、实际时长、按有专注日期计算的日均；当日数据可通过日期框、前后箭头和「今天」查看。与下方近 7 天、近 30 天、全部的范围统计分别标明，避免把区间当作总累计。
- **月度与年度趋势**：按自然月逐日汇总、按自然年逐月汇总，支持前后切换和时间选择，点击圆点查看真实记录。正确处理闰年、跨年、空数据，未来日期不会生成专注值。
- **大屏与性能**：平板并列显示月度、年度卡片，窄屏自动纵向排布；图形按容器尺寸重绘，复用历史索引。照片计时圆盘减少一层嵌套模糊，轻量材质关闭卡片和弹窗的背景模糊。

统计功能只使用本应用已有的专注记录；参考截图中的起床、睡眠、其他 App 使用时长不作为已有数据展示。

## 2.0.2：纯白界面与黑色翻页时钟

首页、卡片、按钮、弹窗与系统栏统一使用纯白底和灰阶文字，点击继续有玻璃流动效果。升级会切换到纯白预设，保留原来的图片文件、计时、任务与记录；在背景设置中选择「我的图片」即可重新使用。

横屏默认显示黑底翻页时钟，数字分成上下卡片，变化时围绕中央转轴翻动。支持当前正计时 / 倒计时、本地时钟和圆环样式，点击右上角切换。只更新变化的数字，退出或进入后台立即清理动画；系统减少动态效果时使用静态卡片。旧版数字样式偏好和备份自动兼容。

大时钟使用纯黑底、白色大数字，控制与圆环采用灰黑色。进入时安卓状态栏与导航栏同步变黑，退出后恢复原界面颜色。计时 / 本地时钟、数字 / 圆环切换继续可用。

## 2.0 新增：计划、专注与复盘

底部增加「计划」入口，首页仍保留计时为主的白色玻璃界面。

- **任务清单**：任务、子任务勾选、三级优先级、截止日期、标签、预计番茄数与完成筛选。点击任务的「开始专注」即可计时；历史按任务 ID 关联，改名后进度保留。
- **专注流程**：首页「循环流程」设置专注、短休息、长休息与 1–12 轮。默认手动衔接，也可自动开始下一阶段；原生服务和闹钟负责后台切换，最后一轮后安排长休息再结束。
- **环境声音**：首页提供雨落窗边、林间微风和午后咖啡馆三种应用生成的合成声景，独立调音量并混合。支持独立试听或跟随专注启停；通知中可停止声音。无须下载资源。
- **周计划与学习日历**：「计划」中切换任务 / 周计划 / 月历，调整每周目标，安排每日计划，查看实际学习记录和本周总结。每日目标仍在设置中调整。
- **桌面小组件**：设置 → 添加安卓桌面小组件，或长按手机桌面后选择璃光。显示当前任务、实时计时、今日时长和下一次重要日期，可开始 / 暂停同一个计时。
- **复盘统计**：保留五种图表，新增本周与上周同期对比、标签汇总、心情分布；点击实际记录可写 240 字以内的感受。统计页可以导出 1080×1560 PNG。
- **备份与恢复**：设置 → 数据备份与恢复，导出包含任务、计划、记录、心情、外观及照片的 ZIP。选择文件后先显示预览，再确认替换；也支持旧 JSON 数据归档。正在计时或暂停时需先结束再恢复。恢复的运行计时变为暂停，声音停止，流程需重新开始。
- **横屏大时钟**：首页「大时钟」可显示当前计时或本地时钟，切换数字 / 圆环样式；进入后保持亮屏，返回键退出。样式选择会保存。
- **重复倒计日**：新增不重复 / 每周 / 每月 / 每年选项，展示下一次日期。月末和闰日自动取该月最后一天，之后继续遵循原始日期。

版本验证、限制及测试入口见 [2.0 验证记录](qa/verification-2.0.md)。环境声是程序生成的合成效果，不是实地录音；组件外观和添加方式由手机桌面应用决定。

## 1.5 新增：性能优化

- 进入统计页、倒计日页时才构建对应内容；开始、暂停及调整计时不再重建未变化的图表。
- 历史记录建立共享的本地日期索引。今日汇总、番茄轮次、热力图及五种图表复用索引，避免为每个日期反复扫描完整历史。
- 计时运行时按秒刷新；空闲或暂停时在下一分钟边界更新日期，界面隐藏时停止轮询，返回前台立即同步原生状态。后台计时仍由原生服务及闹钟负责。
- 白色界面、图片背景和按钮玻璃流动保留；数据与外观不变时复用现有界面元素。

性能基准通过真实 Android WebView 测量，5,000 条记录只存在于 Debug 测试内存，不写入用户历史。优化前后原始结果、测试方法及限制见 [性能验证](qa/verification-1.5.md)。复测命令：`qa/run-performance.ps1 -Gate`（先运行设备回归脚本安装 Debug 和测试包）。

继续使用原发布签名，可直接覆盖升级，保留本地记录与背景。

## 1.4 新增：多图表统计

统计页继续使用白色玻璃风格，提供五种展示：

- **柱状图**：查看各天 / 各周期的专注时长。
- **折线图**：与柱状图共用同一组数据，可随时切换；图表类型会在重启后恢复。
- **环形图**：查看事项时长占比。前 5 个事项单独展示，其余合并；点击图例或环形区域查看对应记录。
- **时段分布图**：按本地结束时间分为 6 个四小时时段，仅累计记录的实际专注秒数。它表示结束时段的积累，不代表恢复出暂停前后的逐小时活动。
- **热力图**：保留近 28 天专注足迹及日期详情。

近 7 天、近 30 天和全部范围统一影响趋势、事项与时段图。全部范围中，较长历史自动按周 / 月 / 年汇总，不丢弃老记录。短时长以秒为单位；无记录时显示空态，不生成虚假的占比。点击趋势点、柱子、事项图例或时段，可查看底层记录。

图表数据层位于 `charts-data.js`，显示与交互位于 `charts.js` / `charts.css`。独立使用本地 SVG 与现有界面，不增加联网依赖。数据检查可运行 `node qa/charts-data.test.js`；设备检查仍使用 `qa/run-device-tests.ps1 -ResetDebugData`。

## 1.3 新增：白色主调与点击玻璃流动

默认使用白色背景、白色半透明卡片和白色主按钮，配蓝灰色文字与柔和阴影。点击按钮时，折光波纹从触点扩散，高光掠过表面，并伴随轻微回弹。效果覆盖计时、导航、时间预设、设置与弹窗中的按钮。

动画不会阻止按钮本身的操作；连续点击替换旧效果，滚动、取消触摸或离开应用会清理动效。系统减少动态效果选项开启时不播放流动动画；外观里关闭液态玻璃也会关闭此效果。轻量材质保留较短的简单反馈。

覆盖升级时会一次性切换为白色主调并提高玻璃遮盖度，原相册背景副本、计时记录和自定义时间保留。之后仍可在外观中自行选择深色界面。新选相册图片也默认搭配白色玻璃。

1.3 设备验证结果见 `qa/verification-1.3.md`，最终 80 项检查可通过 `qa/run-device-tests.ps1 -ResetDebugData` 重现。

## 1.2 新增：GitHub 调研后的三轮优化

研究 Goodtime、Tomato、AndroidLiquidGlass 和 liquid-glass-effect，阅读具体实现后独立优化。项目链接、阅读文件、借鉴点与实现边界见 [调研记录](docs/research-1.2.md)。

- **沉浸专注**：计时卡片右上角进入，仅显示当前计时和控制；退出按钮或安卓返回键恢复普通界面，不会开始第二个计时。
- **延长时间**：运行或暂停的倒计时可以点击“＋5 分钟”，保持已用时长和暂停状态，总时长最多 24 小时；提醒同步延期。正计时无需延长。
- **四轮节奏**：累计每四个自然结束的番茄为一组，完成第四个时优先推荐长休息，仍需用户点击确认。
- **事项统计**：展示当前统计范围内时长最多的 8 个事项、占比、次数；点击事项查看对应记录。
- **日期详情**：点击趋势柱或专注足迹日期，查看当天的实际记录；累计时间精确显示到秒。
- **玻璃升级**：滑动选中胶囊、按住移动时的高光；清透 / 柔雾 / 轻量三种材质。轻量关闭背景模糊和背景过滤，参数会保留以便切回。
- **减少重复渲染**：历史数据按版本增量轮询，不变的时间按钮不重建；页面隐藏时停止界面轮询，原生计时继续。

保留旧数据、相册背景和原发布签名，可直接覆盖安装。

## 1.1 新增：图片背景与液态玻璃

点击右上角图片按钮，或在设置中选择“背景与液态玻璃”：

- 从系统相册选择图片，仅复制选中的图片到本机私有存储，不申请全相册读取权限。图片不会上传到服务器。
- 可切换晨雾、潮汐、落日、星夜四种内置背景；切换预设不会删除已经选过的照片。
- 支持背景模糊、背景遮罩、图片上下位置、玻璃遮盖度，滑动时实时预览。
- 液态玻璃可开关，包含透背景模糊、饱和度提升、反光边缘和触摸高光；不是系统原生材质或物理光学模拟。
- 可分别选择浅色界面 / 深色文字、深色界面 / 浅色文字，适配不同照片。
- 处理大图和照片 EXIF 方向，最长边缩放到 2048 像素，单张导入文件最大 30 MB；只保留一张当前图片的私有副本。
- 支持恢复默认和移除图片；移除只删除应用内副本，不删除相册原图。背景和调节值重启后保留。
- 使用与 1.0 相同的发布签名，直接覆盖安装，无需卸载。

JSON 导出包括外观参数，不包括背景图片本身。旧版 Android 的背景可选格式及材质效果取决于系统图片解码器与 WebView；不支持 backdrop-filter 的 WebView 会使用更实的卡片背景。

## 功能

- 番茄钟：25 / 45 / 60 分钟快捷选择，支持自定义 1 秒至 24 小时；番茄默认时间也可在设置中修改。
- 正计时、倒计时：开始、暂停、继续、结束保存、放弃重置；可为专注事项命名。
- 短休息与长休息：分别自定义时间，休息不会计入专注统计。
- 倒计日：新增、编辑、删除；自定义名称、日期、分类和三种卡片颜色。当天显示 0 天，过去的日期显示已经过的天数。
- 统计：今日目标、实际专注时长、完成番茄数、近 7 天 / 30 天 / 全部记录、每日趋势、近 28 天足迹、连续天数及最近记录。
- 本地数据导出：通过安卓系统文件选择器保存 JSON 数据；当前版本未提供 JSON 导入功能。
- 可选完成声音、前台计时保持亮屏。无需登录，无广告，无网络权限。

## 计时与统计规则

计时状态、事件、设置和历史记录保存在手机私有存储。实际计时优先使用 Android 单调时钟；进入后台、熄屏和重建页面不会重置计时。前台服务显示持续通知，倒计时还使用系统闹钟唤醒完成检查。暂停时间不计入专注，手动结束保存已完成的实际时长；放弃重置不保存当前时段。

只把自然结束的番茄钟计入“完成番茄”；其他专注时段计入次数和实际时长。不足一秒的时段不保存。记录按**结束时的本地日期**归档；跨午夜的整个时段归于结束日期。连续天数统计截至今天的连续有记录日期；今天尚未专注时，允许从昨天向前统计。

系统“强行停止”、关机或厂商后台管控可能阻止到时通知；重新打开应用时会恢复并核对计时。未提供重启后自动提醒。建议在手机系统中允许通知及后台运行。卸载会删除本地记录，请先导出需要保留的数据。

## 打开与构建

在 Android Studio 中打开项目根目录。此电脑已配置 `E:\androidsdk` SDK 和 `E:\androidstudio\jbr` JDK，Gradle Wrapper 为 9.5.0，AGP 为 9.3.3，compileSdk 为 37，targetSdk 为 35，Java 17。其他电脑请修改 `local.properties` 和构建脚本的 SDK / JDK 参数。

$env:JAVA_HOME = 'E:\androidstudio\jbr'
.\gradlew.bat :app:assembleDebug :app:lintDebug

## 结构

- `app/src/main/assets/`：离线界面、液态玻璃样式、交互与统计视图。
- `MainActivity.java`：安卓容器、安全的本地 JS 桥接、权限、文件导出和窗口适配。
- `glass-motion.js` / `white-glass.css`：白色材质与有界、自动清理的按钮流动动效。
- `WallpaperStore.java`：受限的本地图片读取、大图缩放、EXIF 方向处理、图片与外观参数持久化。
- `Store.java`：统一计时状态、单调时间计算、本地存储与记录。
- `TimerService.java` / `TimerReceiver.java`：前台服务、通知、精确闹钟与后台完成处理。

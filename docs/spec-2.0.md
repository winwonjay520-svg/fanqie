# 2.0 实现范围

用户已选择全部建议功能。本轮完成任务与子任务 / 优先级 / 番茄估算 / 标签、原生后台自定义专注流程及可选自动衔接、独立音量的离线环境混音、每日 / 每周目标与周计划 / 学习月历 / 周总结、可操作的安卓桌面组件、任务 / 标签及周对比统计、统计 PNG 导出、含照片的 ZIP 备份与预览确认恢复、横屏大时钟及样式、按周 / 月 / 年重复倒计日、记录关联的心情与感受。

保留白色玻璃风格、点击流动、照片背景、原有正倒计时与五种图表、性能缓存，以及同一发布签名。首页保持简洁，增加计划导航；声音 / 流程 / 大时钟位于首页工具区。新功能使用真实本地数据，无虚构历史。

自动流程在原生 Store / TimerService / AlarmManager 处理，后台到期转换下一阶段，恢复前台不补造多个历史轮次。默认手动衔接；结束当前流程不清理已有记录。环境声音独立的媒体前台服务，受音频焦点管理，支持跟随计时启停。

验证覆盖原有回归、新功能设备场景、日期与统计模型边界、流程后台精确完成与去重、音频生成与启停、小组件真实 RemoteViews、备份往返及恶意 / 损坏输入不影响当前数据，以及发布 APK 覆盖升级。
